# AulaSense - Monitoreo Inteligente de Aulas

Proyecto de Ingeniería en Software
Universidad Politécnica de Querétaro

## Objetivo
Analizar y mejorar el diseño de software de AulaSense mediante cuatro propuestas de arquitectura implementadas en Python y Jupyter Notebook.

- 02-propuestas: cuatro versiones individuales.
- 03-comparacion-final: evaluación de alternativas.
